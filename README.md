# TaskFlow

Sistema de gerenciamento de tarefas desenvolvido como projeto de CI/CD.

## Tecnologias

- HTML
- CSS
- JavaScript
- Node.js
- Express
- PostgreSQL
- Docker
- Docker Compose
- GitHub
- GitHub Actions
- AWS

## Funcionalidades

- Criar tarefas
- Listar tarefas
- Concluir tarefas
- Excluir tarefas
- Definir prioridade
- Definir prazo

Frontend → Backend → PostgreSQL
